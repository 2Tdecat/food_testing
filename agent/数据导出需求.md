在首页增加一个"导出"按钮，点击按钮后进入"数据导出"页面，数据导出页面支持按日期查询所有类型的本地数据。页面上方是日期范围选择区域，下方是数据展示区域；日期范围选择区域默认的时间范围是今天；数据展示区域左侧是数据类型（如：绵白糖、红糖还原糖、还原糖、总糖、淀粉等），右侧是按日期展示的数据，支持按日期和单条数据勾选；默认勾选今天的所有类型的数据，切换日期后自动勾选指定日期内的数据；点击导出后将所有数据汇总到一个 excel 文件中导出，一种类型的数据放到一个表中，每个表的表内格式与现在的导出格式相同。

## 需求 2：数据导出页面（按日期查询 + 类型/日期/单条勾选） ✅

新建 [DataExportView.vue](../src/views/DataExportView.vue)：

### 页面结构（上：日期范围选择；下：左类型 + 右数据）

- **日期范围选择区域**：顶部卡片显示"开始日期 至 结束日期"，点击弹出 t-calendar（type=range、allow-same-day）选择范围；默认今天；minDate 显式设为 2000-01-01（t-calendar 默认最小值为今天，必须放开才能选历史日期）、maxDate 为今天
- **左侧数据类型列表**：绵白糖 / 红糖还原糖 / 还原糖 / 总糖 / 淀粉 / 干浸出物，每项显示"已勾选/总数"计数；初始定位到第一个有数据的类型（无数据回退绵白糖）；点击切换右侧展示
- **右侧数据展示区域**：按日期倒序分组（组头显示日期 + 条数，带日期级勾选框，支持全选/半选态），组内为记录卡片（模式标签 + 样品名称/编号 + 保存时间 + 结果四格：含量₁/含量₂/平均值/相对误差，超精密度限值标红），点击卡片或勾选框切换单条勾选
- **底部操作栏**：全选/全不选（作用于范围内全部类型）、已选条数与日期范围摘要、"导出 Excel"按钮（已选 0 条时禁用）

### 勾选行为

- 进入页面默认勾选今天全部类型的数据（当天无数据则已选 0 条）
- 日历确认切换日期范围后，自动勾选新范围内全部类型的数据（清空旧勾选重建）
- 手动取消某类型/某日期/某条数据的勾选后，只要不切换日期范围，勾选状态保持（全选按钮可一键恢复范围内全部）
- 勾选 key 为 `类型|记录id`，跨类型不冲突

## 需求 3：汇总导出到一个 Excel（每类型独立 sheet，格式与单独导出一致） ✅

[exportExcel.ts](../src/utils/exportExcel.ts) 重构 + 新增：

### 重构：抽取 sheet 构建函数（为复用单独导出格式）

- 各类型导出拆为"构建 sheet（返回 SheetSpec：名称 + 工作表）"与"写入文件"两步：`buildSucroseSheet` / `buildReducingSheets` / `buildTitrationSheets` / `buildTotalSugarSheets` / `buildStarchSheets` / `buildDryExtractSheet`，`appendSheets` 统一附加到工作簿；原 `exportXxxHistory` 系列函数行为不变（仍单独导出各自文件）
- `download` 收敛为 2 参数（wb, baseName），列宽由各 build 函数内部设置（此为并行会话遗留的类型错误修复点，见 [干浸出物需求.md](./干浸出物需求.md) 验证节）

### 新增：exportCombinedHistory（多类型汇总导出）

- 入参 `CombinedExportData`（仅传需要导出的类型与记录数组）+ 可选日期范围
- 按固定类型顺序组装 sheet：绵白糖蔗糖分-5012 → 红糖还原糖（+ 表2-f系数 查表页，供 K 列插值公式引用）→ 还原糖正滴/反滴 → 总糖正滴/总糖正滴（蔗糖计）/总糖反滴/总糖反滴（蔗糖计）→ 淀粉一法/淀粉二法/淀粉1法反滴/淀粉2反滴 → 干浸出物；多模式/方法类型按现有单独导出规则拆分为多个 sheet
- **每个 sheet 的列布局、公式、列宽与该类型单独导出逐单元格完全一致**（构建函数直接复用，保证"表内格式与现在的导出格式相同"）
- 文件名：单日 `数据导出_YYYYMMDD.xlsx`，跨日 `数据导出_YYYYMMDD-YYYYMMDD.xlsx`，未传范围时用当天日期戳
- 空数据（全部类型为空数组）不触发下载；页面导出前已按勾选过滤记录，无勾选时 Toast 提示并拦截
